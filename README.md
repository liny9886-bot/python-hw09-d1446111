## 三、個人回答

### 問題一：測試一中，整理後的桌遊串列有 4 筆資料，為什麼桌遊費用應以 3 人計算？直接把字串拆成 list，和再轉成 set，各自保留了什麼、失去了什麼？
* **以 3 人計算的原因**：因為名單中有人重複報名（例如 `"Amy"` 與 `"amy"` 經過清理後重複出現），根據規則「同一個人在同一場活動中重複出現，只算一位參加者，也只收一次該場費用」，因此必須先透過 `set` 去重，得出 3 位實際參與的唯一姓名，再進行收費計算。
* **直接把字串拆成 list 的特點**：保留了原始報名的順序、所有填寫記錄以及重複報名的完整次數，但無法直接得知正確的真實人數。
* **轉成 set 的特點**：自動消除了重複項目並去除順序，精確保留了「參與者的唯一集合（不重複名單）」，但失去了原始報名的先後順序與重複報名的次數資訊。

### 問題二：測試三中，兩場活動只有 3 位不同的人，為什麼是 6 人次、總應收仍是 600 元？請用集合關係與算式說明。
* **原因說明**：雖然從「總不重複人數」來看只有 3 個人（`amy`, `ben`, `cora`），但這 3 個人兩場活動都完整參與了（即桌遊去重人數為 3，電影去重人數也為 3）。
* **算式與集合關係**：
  * 報名人次 = 桌遊去重人數（3） + 電影去重人數（3） = 6 人次。
  * 總應收 = 桌遊應收（3 $\times$ 120 = 360 元） + 電影應收（3 $\times$ 80 = 240 元） = 600 元。
  * 費用是以「各場活動去重後的實際參加人數」獨立計算，而不是用總不重複人數乘上單一活動費用。
